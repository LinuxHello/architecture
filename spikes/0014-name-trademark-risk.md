# Spike: Trademark risk of the name Linux Hello

## Question

Is 'Linux Hello' likely to conflict with Microsoft's 'Windows Hello' trademark or any registered mark, and what are the fallback names?

## Time box

Proposed: 2 working days. Stop at the time box and record what is known.

## Method

Search the EUIPO, USPTO and WIPO databases; record findings and two fallback names. Not legal advice.

Nothing has been run for this note yet. Mark each command and script tested or untested, with versions and hardware class, when the spike is run.

## Blocks

The name is a one-way door: package names, D-Bus names and links depend on it. Blocks the crate and package names ADR ([#22](https://github.com/LinuxHello/linux-hello/issues/22)), the D-Bus name ADR ([#17](https://github.com/LinuxHello/linux-hello/issues/17)) and the first release.
